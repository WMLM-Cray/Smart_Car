# 路段训练计划

更新：2026-09-26。本文记录当前训练目标和验收边界，旧租机方案与旧模型结论已过时。

## 目标

训练一套能在走廊中行驶、并能迁移到 A–D 赛道的策略。先从路段生成器开始，不从赛道生成器开始；队友的训练任务独立，训练环境和模型由本项目维护。

## 方法

1. 生成直道、弯道、直角、S 弯、掉头、变宽和缺口等开口路段。
2. 每张地图先验证连通、车体净空及教师可达；不通的地图不进训练集。
3. 按课程逐步增加困难路段；速度从早期开始随机化，不留到后期补。
4. 训练动作输出转向与目标速度，速度范围 0.45–1.0 m/s。PID 将目标速度换成 PWM，ESC 起转平台由最低速度和动力模型表达。
5. 先用 FastSim 筛选，再用 Gazebo 和实车独立验收；不同环境结果不可互相代替。

当前代码：`road.py`、`road_check.py`、`road_env.py`、`road_teacher.py`、`road_policy.py`、`road_train.py`。车辆轴距 0.33 m；转向来自实测曲线。最低起转速度随电压和负载变化，现有范围仍是模型近似。

## 边界

- 不训练 PWM 直接输出；不抬高实车 1620 PWM 硬上限。
- 规则图坐标是估读数据，未经尺寸校准的 A–D 地图不作为最终通过率门槛。
- 教师失败先修几何、可观测性或控制约束，不把不可达动作当标签。
- 训练成功率只对记录的代码、配置、种子和地图有效；最终测试种子独立于训练和选模。

## 验收

每级地图均通过可通性检查；训练报告记录版本、速度分布、每级通过率、失败原因和逐局结果。候选再进入 Gazebo A–D 配对测试及实车测试。没有对应证据时标记“未验证”。

训练命令示例：

```bash
python -m fastsim.road_train --out runs/road_trial --workers 8 --torch-threads 2
```

恢复训练加 `--resume`；从 road_v2 权重热启动用 `--init model.npz` 并写入新目录。服务器资源上限按与队友协调结果配置，不默认占满整机。
