## 1. 更正声明(v1 → v2)

1. **撤销 G5"4m=弧长"**。v1 用"拟合弧长≈4.1m"证明顶部外凹弧弧长=4m,依据不成立。
   4m 实标在一条**直的斜向尺寸线**上(§2.4)。原 R2.11/R3.16 弧参数降级为像素拟合候选,
   本版由尺寸链重新求解(§3)。
2. **v1"4m 两点 3.712m 系误读"表述错误**。3.712m 的距离计算没有错,
   错在那两个坐标点对应的是 45° 标注的元素,不是 4m 尺寸线的端点;
   不能改写成"计算时把 45° 认成 4m"。
3. **v1"边界已闭环、仅一处 0.17m 容差"不成立**。v1 报告手填端点后声称共点,
   实际右侧内弧→黄V圆弧断口 0.315m、内凹弧→连接直线断口 0.183m。
   本版所有端点由公式/共享变量计算,连接误差由程序输出(§4.1),缺口>0.05m 显式 FAIL。
4. **黄V"带厚 1.5m"不能当道宽**。两边界竖直落差 1.50m、臂与水平成 22.5° 时,
   垂直于边界的间距=1.5×cos22.5°≈1.386m。两种读数都记录,不靠措辞调和(§4.3)。
