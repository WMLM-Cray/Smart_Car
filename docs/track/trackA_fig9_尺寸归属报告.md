## 1. 更正声明(v2 → v3,如实记录)

1. **右端半圆被 v2 改错,本版恢复**。v2 源码把右端外边界生成为"顶部 90° 弧 + 竖直段 + 底边"
   (外弧从顶切点走 90° 到右切点 (16.8,2.75),竖直下到 (16.8,0),再沿底边返回),内边界同样处理。
   这使右下圆弧消失、变成直角,与原图和 v1 均不符。
   正确结构:**右端为完整 180° 半圆**(外 R2.75、内 R1.25,圆心 (14.05,2.75)),
   底部直道为**单段直线**,直接连接左右两圆弧的下切点 (2.75,0)→(14.05,0)(§3)。
2. **左下 2.75m 折返漏检,检查器已升级**。v2 外环 E12 沿底边 (16.8,0)→(0,0),紧接着 E1 又返回
   (2.75,0),同一段边界被反向重复走了 2.75m。v2 检查器用 %180 计算切线夹角,把 180° 折返算成 0°平滑,
   且无重叠检查,所以"全绿"。本版检查器改为:①用**有向切向量**计算夹角(保留 180°,>170° 报折返);
   ②增加**非相邻段重叠/自交检查**;③**selftest** 用已知坏环证明检查器会报警(§4)。
   v2 的"连接误差全 0"结论随之作废:那只能证明端点相接,不能证明边界合法。
3. **撤销"顶部凹弧尺寸驱动定案"**。v2 的四个弦端点仍是手填的包络坐标,再与 P1/P2 三点定圆;
   尺寸链只提供了其中一个点(P1 或 P2),不能据此确认整条圆弧。v2 运行结果中顶部弧与顶线连接处的
   46°~65° 折角是**该模型的输出**,不能列为"官方折角"。本版把三点定圆降级为 **CAND-A(候选)**,
   并按审查建议验证了 **CAND-B(圆心链候选)**:左下弧圆心 LL(2.75,2.75)、上方 V(5.578,5.578)、
   右侧 W(8.407,2.750) 作为三个相邻圆弧的圆心,半径 2.75/1.25/2.75,圆心距 4 = 2.75+1.25,
   构成相切圆弧链。程序验证该候选的多项几何关系全部成立(§5.2),但同样不定案。
4. **撤销"道宽官方冲突"表述**。v2 表中"凹弧谷 1.361 冲突""垂直间距 1.386 冲突"的措辞越权:
   凹弧宽度来自尚未成立的圆弧模型;黄V的竖直偏移 1.50 是代码主动设定的(包络肩部落差),不是官方尺寸。
   本版统一表述为 **"当前重建尚未同时满足尺寸和道宽约束(开放问题)"**;
   两条不同圆心圆弧的谷底高度差**不等于**已验证的局部最短道宽(最短道宽须先确认弧模型才能计算);
   程序输出中已删除把旧误读写成规则原文的 "rule text" 字样。

## 4. 检查器 v3 与运行结果

三项独立检查(每环分别跑):

1. **连接 gap**:相邻段端点距 >0.05 m 显式 FAIL。结果:外/内环 20 个接缝全部 0.0000。
2. **有向切向量夹角**:按行进方向取每段起点/终点切向量,夹角 wrap 到 (−180°,180°];
   >170° 报 **BACKTRACK/REVERSAL** 并计 FAIL,>0.5° 标 corner。
   结果:平滑处 0.00°(底边↔半圆切点、左下弧↔直边、顶线中段等);
   corner 处 43.6°~90°(直角、V 顶角、V 肩、CAND-A 弧-线连接——后者为模型输出,非官方折角);
   **无 BACKTRACK**。
3. **非相邻段重叠/自交**:每段按 0.05 m 采样,非相邻段对最小距 <0.03 m 报 FAIL。
   结果:两环全部段对 ≥0.03 m,none。

**selftest(证明检查器有效)**:构造 v2 的坏环——B1 (16.8,0)→(0,0) + B2 (0,0)→(2.75,0):
- 有向切角 = 180.00° → **CAUGHT**(v2 的 %180 在此处算 0°,漏检);
- 重叠最小距 = 0.0000 m → **CAUGHT**。
两项均报警,检查器不再是"只会说好"的检查器。

> 教训(写入交付):**连接误差为零不代表边界合法**。检查器必须独立于重建参数验证
> 方向、重叠与自交,否则"闭环"只是自洽。

## 5. 顶部凹弧:双候选并列(未定案)

尺寸链在顶部只给了两个点(P1、P2)与顶线高度;弦端 x 坐标只能来自像素包络。据此形成两个候选:

### 5.1 CAND-A:三点定圆(v2 模型,降级为候选)

外弧过 OUT_A(3.80,5.60)、OUT_B(7.30,5.60)、P2;内弧过 IN_A(3.00,4.15)、IN_B(7.75,4.15)、P1。
程序解:外 c(5.550,6.434) R1.939 谷(5.550,4.496);内 c(5.375,6.420) R3.285 谷(5.375,3.135)。
- 弦端与包络吻合(端点即取自包络);**但弦端是像素值,只算辅助定位**;
  尺寸链仅提供 P2 一个点,三点定圆中有两点非官方 → 不能称"尺寸驱动定案"。
- 弧与顶线连接折角 63°~65°(模型输出,**不列为官方折角**;官方图上是否折角连接未证实)。

### 5.2 CAND-B:圆心链相切圆(本轮新增验证)

候选解释:LL(2.75,2.75) / V(5.578,5.578) / W(8.407,2.750) 为相邻圆弧圆心,半径 2.75/1.25/2.75,
尺寸链上的 1.25 与 2.75 对应半径,相邻圆心距 4 = 1.25+2.75 构成**相切**圆弧链。程序验证:

| 关系 | 数值 | 判定 |
|---|---|---|
| \|LL−V\| | 4.000 = 2.75+1.25 | **TANGENT(精确)** |
| \|V−W\| | 4.000 = 1.25+2.75 | **TANGENT(精确)** |
| LL×V 切点 | (4.695,4.695) | 与链分点 P2 偏差 **0.0000** |
| V×W 切点 | (6.462,4.695) | 在链延长结构上 |
| \|LL→P1\| | 1.250 = R_LL_内 | P1 恰在 LL 内圆上 |
| 链段分解 | 1.25 / 1.50 / 1.25 | = R_内 / (R_外−R_内) / R_V,自洽 |
| V圆×顶线 y5.60 | (4.329,5.600)、(6.828,5.600) | 弦端恰落在顶线上 |
| P2 在 V 圆下弧上 | 角度 −135.0°,在扫程内 | 成立 |

即:**链线的三段长度可以被"LL内圆半径/半径差/V圆半径"完整解释,切点与链分点重合到小数点后四位**。
这比 CAND-A 更充分地利用了官方尺寸——但它是"需要验证的候选解释",不是官方确认。

### 5.4 结构发现(开放问题,不是结论)

- 若外凹弧=V圆 R1.25,则**内边界无法用同心偏移生成道宽 1.5**(1.25<1.5)——
  CAND-B 与统一道宽 1.5 结构性冲突;内弧须另有圆心/另解。
- CAND-B 中 **W 圆(R2.75,顶点 (8.41,5.50),近黄V左肩)尚无边界段归属**,作用未解。
- CAND-A 满足道宽仅靠未确认的弦端;CAND-B 利用官方尺寸充分但形状偏差更大(谷差 0.282、端点内缩 0.5)。
- **两候选均不定案**;顶部模型(或都不是)待审查/问组委会后裁决。
