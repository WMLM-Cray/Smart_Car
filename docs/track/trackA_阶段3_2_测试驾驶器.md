# trackA 阶段3 第二步:仿真测试驾驶器(交付记录)

日期:2026-09-16 | 分支:integration/trackA-sdf | 状态:**已完成,四段全 PASS(含整圈)**

## 一、身份声明(任务书要求)

`tools/trackA/test_driver.py` 是**仿真测试驾驶器**:在仿真中沿预先由冻结赛道
几何算出的车道内参考路线低速行驶,用于驱动建图/定位/导航验收。它**不是自主
探索,不是 Nav2,无感知避障**。轨迹跟踪反馈使用 Gazebo 真值(`/model_states`),
真值仅用于驾驶器跟踪与验收记录;SLAM 链路只用模拟传感器 `/scan` 与正常 TF,
无任何真值注入。节点名 `sim_test_driver`,所有日志前缀 `[仿真测试驾驶器]`。

## 二、任务书硬性要求逐条落实

| 要求 | 落实方式 | 结果 |
|---|---|---|
| 1. 参考路线查整车轮廓余量,不得锥桶坐标连线当路线 | 车辆按冻结 params.yaml 底盘 0.56×0.35m 矩形(轮外缘 0.30+0.05=0.35 与底盘同宽),锥桶按 0.28×0.28 方底座外接圆 r=0.198;路线每 0.05m 采样对全部 63 锥逐一算"矩形-圆"间隙;**发动前静态预检,最小间隙 <0.298m(锥 0.198+余量 0.10)即拒绝行驶** | 四段预检 0.575/0.554/0.471/0.471m 全过 |
| 2. 速度/转向满足阿克曼约束,低速 | v=0.3m/s,\|ω\| ≤ v·tan(0.55°)/0.36(冻结 wheel_base/max_steer)硬限幅 | 实测最大 \|ω\| 0.364(限 0.511) |
| 3. 先一小段,逐段扩展到一圈 | --route short(2m)→u_right(9.3m)→half(27.8m)→full(36.1m 整圈) | 逐段全 PASS |
| 4. 失速/碰撞/偏出即停车报告,不硬闯 | 横向偏差>0.35m / 整车间隙<0.228m / 5s 进度<0.05m 三监控即停;终点亦停车 | 全程未触发 |
| 5. 运行时键盘/手柄/Nav2 速度输出失效 | 启动时 `count_publishers('/cmd_vel')`>0 拒绝启动,运行中每 2s 复检,>1(自身之外)即停;编排脚本只起 sim_bringup(不含 teleop/手柄/Nav2) | 全程独占 |
| 6. 不修改冻结赛道/车辆几何 | 路线常量只读 CSV 推导,锥桶零改动 | ✓ |

## 三、参考路线推导(依据冻结 trackA_cones.csv 63 锥,零改动)

按 segment 分组重新核对锥桶布局后确定(与早期记忆不同处已修正):

- **底道**:锥排 y=0(E1)/y=1.5(I1),x∈[2.75,14.05] → 中线 **y=0.75**;
- **右U弯**:内环红锥 R=1.25 圆心(14.05,2.75),外环蓝锥 R≈2.75 → 同心中线
  **c=(14.03,2.75) R=2.0**,270°→90° 逆时针,与底/顶道无缝相切;
- **顶右直道**:走廊 [4.0,5.5]（I2/E2）,中线 y=4.75,x∈[8.41,14.03]。
  官方图的"黄胶带V区"(x≈8.3~13.9)在冻结 world 中无实体无锥,直行通过,
  若后续规则明确黄区绕行再调;
- **锥桶V谷**(左半):内红外蓝锥对中点折线 (8.41,4.75)→(5.578,3.578)
  →(2.75,4.75),谷深 1.17m(早期记错为右半 x≈11.2,已按 CSV 修正);
- **左U弯(重要发现)**:单圆弧 c=(2.75,2.75) R=2.0 **不可行**——内岛是直角
  块,左上角锥 I8(1.5,4.0) 距该弧仅 0.23m,整车矩形间隙 0.057m<0.298,
  静态预检 FAIL 即拒绝发动。改为**三段复合**:
  ① 切角小弧 c=(1.75,3.75) R=1.0(90°→180°,同时避开外角(0,5.5)与 I8);
  ② x=0.75 直线下行(左墙 x=0 与内岛左缘 x=1.5 的中线,走廊恰 1.5m);
  ③ 左下大弧 c=(2.75,2.75) R=2.0(180°→270°,与外缘 E10 弧 R≈2.744 同心)。
- 整圈里程 **36.07m**,逆时针,起终点均为出生点 (11.0,0.75)。

## 五、启动方式(入库)

```bash
# 无头分段验证(WSL):
bash tools/trackA/test_driver_run.sh short|u_right|half|full
# 整圈 + SLAM + RViz 截图 + map_saver(第三步地图来源):
bash tools/trackA/test_driver_map_run.sh full
# 直接跑(需已起 sim_bringup 并 source):
python3 tools/trackA/test_driver.py --route full [--speed 0.3] \
    [--cones docs/track/trackA_cones.csv]
```

控制:纯追踪(前视 0.55m,20Hz Twist);终点前 1.2m 线性减速至 0.12m/s;
退出/中止均发零速(另有 sim_wiring 0.5s 看门狗兜底)。
