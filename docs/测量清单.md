# 实车参数测量清单(阶段 1 人工展示验收配套)

> 目的:仿真 `config/params.yaml` 中标注 `[实测]` 的参数当前全是**假设值**,

## 6. 测量后回填步骤

1. 编辑 `hwcart_sim/src/racecar_sim/config/params.yaml`,逐项替换假设值

3. 重跑验收:`bash ~/hwcart_sim/tools/verify_phase1.sh`(测距判据期望值
   `5.75−雷达前偏` 会随 `laser_x` 变化,若实测值≠0.07 需同步改
   verify_phase1.sh 中 scan_range 的期望区间)
