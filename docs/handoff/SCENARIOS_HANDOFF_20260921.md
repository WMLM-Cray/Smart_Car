## 2. 三场景（二维已跑，三维照抄几何）

统一：起点 (0,0,0)、dt=0.01s、预算 120s。

| 场景 | 起 → 终点 | 路径约束 | 障碍 | 任务点（分别判定） |
|---|---|---|---|---|
| S1 直行单点 | (0,0,0) → (2.0,0) | 直线 | 无 | (2,0) |
| S2 含转弯两点 | (0,0,0) → (1.5,0) → (1.5,1.5) | 90° 直角 | 无 | (1.5,0)、(1.5,1.5) |
| S3 绕障净空 | (0,0,0) → (2.0,0) | 参考折线：`(0,0)→(0.4,0)` 直行 + 以 (1,0) 为心 R=0.6 上半圆弧到 `(1.6,0)` + 直行到 (2,0) | 障碍锥 (1.0,0,r0.14) | (2,0) |

> **S3 定位 = 给定绕障参考路径的跟踪与净空验证，非自主避障规划、非 Nav2 规划。**
> 参考弧 R=0.6 略大于最小转弯半径 R_min=0.587（`wheelbase/tan(max_steer)`）。
> 该半圆弧端点切线 +y(进)/−y(出)，与终点直行 +x 有 90° 不连续，是参考路径几何特性——
> 故 S3 朝向判据预期不达标，如实标即可，别去改弧凑朝向。

## 4. 三种参数变体（二维=同一动力学，三维对应换参数）

| 变体 | 速度上限 | 执行器死区 | 二维参照值（S1 直行 2m） |
|---|---|---|---|
| A 原模型 | 1.5 / 0.5 m/s | 无 | 3.85s 到位 |

| C 假设0.48m/s死区变体 | 0.10 / 0.05 m/s | **速度域对称死区 0.48m/s（假设）** | 未起步，120s 超时 |

> **死区模型形式（重要，照此实现，别画蛇添足）**：作用在**速度命令 v_cmd（单位 m/s）**，
> 位置在 **min(v_max) 限幅之后、车辆动力学之前**，形式 = 对称死区 **`|v_cmd| < 0.48 → 0`**。
> 这是"485mm/s≈1588µs"口径在速度域的折算（**假设**），**不等于**已标定实车最低可控地面速度，
> **不据此建议提高限速**。
