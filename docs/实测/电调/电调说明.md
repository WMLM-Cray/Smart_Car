## 说明书写明的特性

| 项 | 说明书 | 对我们意味着什么 |
|---|---|---|
| 电机类型 | 只支持**无感**无刷电机 | 低速有最低稳定转速 → 起步就是 ~0.5 m/s 的平台,没有更慢的速度 |
| 保护 | 低压、电调过热、电机过热、油门信号丢失、**堵转(Motor blocked)** | 堵转保护的触发条件、恢复方式说明书**没写** |
| 自动关机 | 低压保护后 2 分钟关机;**其他情况 5 分钟无操作自动关机** | 就是 10-12 实测的"闲置 ~5.5 分钟后什么油门都不认",要按电子开关重开 |
| 低压保护 | 降到 40% 功率 20~30 s 后切断,电机"嘀嘀"、LED 闪 | 默认 3.3 V/节,3S = 9.9 V(静态 10.6 V 时起步瞬间可能压到) |
| 油门行程设置 | 按住电子开关上电进入,依次推满油 / 拉满刹 / 回中位,各"嘀嘀"一声 | 说明书说"没设过就不用设",出厂有默认行程 |
| 上电 | 油门在中位时电机"嘀嘀"表示就绪;只有"嘀"一声要调发射机 TH.TRIM 回中位 | 上电时油门必须落在中位区间里才解锁 |

## 和我们实测的对照

| 实测现象 | 说明书怎么解释 | 状态 |
|---|---|---|
| 闲置 ~5.5 / ~6.2 分钟后直跳 1600 也不动,重开电调就好 | 5 分钟无操作自动关机 | **确认** |
| 中位附近 1500~1545 都是滑行、互相没区别(09-22) | 中位区间 9%:按 1000~2000 µs 满行程算是 ±45 µs,以 1540 为中心是 1495~1585 | **吻合**(行程按标准值推算,没实测) |
| 高位破静 ~1590~1594,1582 以下不动(09-30 `12v40_high_nomove_to1582`) | 前进从中位区间上沿 ~1585 才开始出力,再加几个才够转起来 | **吻合** |
| "上电锁中位":上电时收到 ~1500 整条曲线下移 ~40(低位破静 1552) | 说明书只说上电时油门要在中位;实测像是**把上电那一刻的油门当中位中心**,±45 区间跟着平移(1500+45 ≈ 1545,破静 1552) | **推断**,说明书没写 |
| 松油门滑行 0.7~1.0 m/s² | 拖刹默认 0%:中位就是自由滑行 | **确认** |
| 中位以下:跑着是刹车(1.3~1.9 m/s²),≤1.0 m/s 后直接变倒车 | 默认运行模式"前进/倒车/刹车",最大刹车 50%,最大倒车 25% | **确认**模式和力度来源;"停下自动转倒车"的细节说明书没写 |
| 停在 1580 后再加油门不认、慢爬爬不起来,回一次中位再直跳就动 | 有堵转保护,但没写触发和恢复条件 | **推断**:转不起来被当堵转切断,回中位解锁 |
| 起步就是 ~0.5 m/s 平台,没有更慢的速度 | 无感电机 + 启动模式 Level 3 | 机理吻合 |

## 对代码和仿真的影响

- 速度环阶梯起步(`vehicle/speed_loop.py`,04331c1)针对的就是堵转保护:车停着不慢爬,不动就回中位再跳高。
- 车停着 **5 分钟**电调会自己关机,之后必须按电子开关重开。自动驾驶放行前车停太久就会"放行了不走"。
- 仿真动力学该照这里改:中位 ±45 死区、无刹车拖拽(滑行只有滚阻)、刹车上限 50% 档、停车后中位以下是倒车。

## 想改设置时(要买编程卡;比赛不一定需要)

- **运行模式 → 前进/刹车**:去掉倒车,刹车就不会变成倒车。
- **最大刹车 → 75% / 100%**:刹车更强,刹车距离更短。
- **启动模式 → 更高 Level**:起步更有力,破静点可能下降。
- **中位区间 → 6%(Narrow)**:死区变窄(±30 µs),油门更早出力。
- 改任何一项后,速度环的破静、维持、平台都要重测(`calibration/ramp_curve.py`)。
