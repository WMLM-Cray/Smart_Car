# 2026-09-30 落地速度曲线(电池静态 12.40 V,电调关闭时量)

同一块电池、同一电压,**电调断电重上电前后曲线整体差 ~40 PWM**,平台速度不变。
工具:`python3 -m calibration.ramp_curve`(雷达防撞开,每段 ≤5.5 m;场地 ~7 m,分段测)。

## 两种状态

| | 低位(当天开机后,电调未重上电) | 高位(用户关电调量电压后重上电) | 2026-09-24(12.5 V) |
|---|---|---|---|
| 破静点(静止起步) | 1552 | 1594 | 1594 |
| 最低维持(跑着不停) | 1544(1543 塌到 0.27) | 1586(1585 → 0.49,1583 → 0.08) | 1584 |
| 平台 | 1544~1566 ≈ 0.67 m/s | 1586~1605 ≈ 0.67 m/s | 1588~1602 ≈ 0.66 |

两种状态破静点都比某个"中位"高 ~52~54。**已实证:电调上电时把收到的油门信号锁成中位。**
架空:上电时持续发 1600 → 轮子不转;之后在 1600 保持 10 s 轮子静止,1540 时轮子**反转**。
所以高位 = 上电时收到 1540;低位 = 上电时收到的是 ~1500(当天早上车开机时底盘发的值,未查)。
**安全含义**:全部代码把 1540 当"停车",中位锁错时"停车"就是在给油或倒车。
操作规程:车上服务起来、持续有 1540 之后再打开电调开关;或用 `calibration.esc_rearm`(全程发中位)。

## 低位曲线

- 下降段(1565 → 1540,每 0.2 s -1):1545~1565 ≈ 0.66~0.70,1544 0.63,1543 0.27,1540 0.16(在滑)。
- 上升段(每 0.15 s +2,**非稳态,偏低**):1580 0.95、1590 1.37、1602 1.87 m/s,1.9 m/s 时防撞收油。
  低位时 1620 远超 2 m/s,1592 以上没测稳态(要更长直道)。

## 对控制的影响

- 速度环 floor 写死 1590:高位正好;低位时最低就是 1.37 m/s(当天策略跟不住 0.6、Sloth 也到 2 m/s 的原因)。
- "死区内起步跳点"不能写死(低位时 1575 ≈ 0.8 m/s),已撤回。
- 需要:开机/起步时在线学破静点,floor = 破静点 − ~8;或者保证电调每次上电时收到的都是 1540。
