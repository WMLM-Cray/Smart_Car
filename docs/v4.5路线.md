## 名字

| 名字 | 是什么 |
|---|---|
| **v4.5** | 这一轮从头重训的训练线(10-19 定) |
| **v4g** | v4 bev 训练 g 组第 9 个 candidate;现在的回滚模型,拿来比 |
| **r1A_064** | 车上开机模型 |
| **A** | v4.5 基线:网络和 v4g 一样,输入 bev_v2,新速度契约,从头训 |
| **A0** | A 的对照:速度契约换回老的(只滑行),只跑第 1 段 |
| **B_alpha** | 输入线:新 BEV bev_v2.5(多一张 5 cm 近场图),其余同 A |
| **B_alpha'** | B_alpha 的归因对照:近场图先合成 10 cm 再放大 |
| **B_beta1** | 网络线:卷积加宽 + 残差块,输入仍是 bev_v2 |
| **B_beta2** | 网络线:全连接加宽到 512,输入仍是 bev_v2 |
| **bev_v2** | 现在的输入:6 × 80 × 80(10 cm/格,车前 6 m、车后 2 m、左右各 4 m)+ 3 个标量 |
| **bev_v2.5** | bev_v2 + 64 × 64 的 5 cm 近场图(车前 2.6 m 到车后 0.6 m、左右各 1.6 m);和 bev_v2 并存 |
| **新契约** `_s5_v0.45-5_d0.2_log` | 速度输出分三段:前进(对数 0.45–5 m/s)/ 中位滑行 / 刹车 |
| **老契约** `_s3_v0.45-3` | 只有前进和滑行 |
| **第 1 段** | DAgger 模仿老师(`training/bev_train`),20 轮,每轮存一个 candidate |
| **第 2 段** | 开放场景 RL(`training/explore_rl`),从第 1 段挑出的 candidate 起步 |
| **L 弯测试** | `evaluation/l_test`;主指标 = 转向起始点(离前墙多远开始转),通过率当护栏 |
| **M4 / M6 / 虚拟机** | 训练机器,数字见 [训练机器.md](训练机器.md);M6 已到期 |
