## 如实结论

1. **速度上限是敏感性主因素，但不下"首要鸿沟"结论**：A(1.5)/B(0.10) 设置上限比 **15 倍**；
   完成时间比 ~5.3–6.6 倍（3.85→20.38s 等），不等于 15 倍（接近终点减速+停车为固定开销）。
   需区分三档：**物理上限 3.0[假设] / A 组设置 1.5[代码] / B 组设置 0.10[配置]**。
2. **死区 → 未起步是"假设死区模型"的结果，非实车验证**：C 组在速度域加对称死区
   `|v_cmd|<0.48→0`（输入单位 m/s，施加于限幅后、动力学前），0.10 < 0.48 故全程未动。
   这**不是**把 PWM 起转阈值直接等同最低可控地面速度，**不据此建议提高限速**。
3. **S2 朝向差异真实**：A(1.5) 过 90° 直角弯后出弯朝向 0.468 未对齐（✗），B(0.10) 0.349 对齐（✓）
   恰在阈值两侧——速度影响过弯后的航向对齐，纯追踪高速切角更狠。
4. **S3 = 给定绕障参考路径的跟踪与净空验证**（非自主避障规划）：A/B 沿同一参考弧
   R=0.6 跟踪，净空 5.8/7.0cm（外轮廓口径）无碰撞。朝向 ✗ 因参考弧末端切线 −y 与终点
   直行 +x 存在 90° 不连续（参考路径几何特性，非车辆模型能力；要朝对齐需加调头段，本轮不含）。
5. **实车推车口径修正**：每计数距离 = `3.57×0.25×1.03×227.45/1024` = **0.2042mm**（含 0.919275
   系数），**非** C/1024=0.2221（漏系数误算）。三段前进1/2、后退1 实测 0.2076/0.2064/0.2018
   → +1.7%/+1.1%/−1.2% 吻合；**前进3 保留异常**（真实窗口 Δ=4242，0.1886mm/计数，−7.6%，
   编码器多计 ~6.6cm）。

## 未通过 / 未证实（诚实声明）

- **不宣称已完成实车迁移**：速度上限/死区标定全依赖 §7 待测项。
- **推车数据只能证明**编码器计数↔卷尺距离的行程积分一致性（三段 ±2%），**不能证明**
  动态响应/制动/最小可控速度（无动力）。
- 死区两口径（485mm/s≈1588µs vs ±60µs）**并存未裁决**，本轮按口径①速度域折算做敏感性。
- 传感器频率配置值 12Hz ≠ 实测 11.99Hz；安装高度（laser 0.21/imu 0.18/camera 0.24）仍假设。
