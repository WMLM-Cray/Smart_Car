# 正 / 零 / 负 PWM 历史日志索取清单（2026-09-19）

> 目的：坐实 driver 公式 `motor_pwm = v×100 + 1540` 的**正 / 零 / 负三个方向分别对应什么
> 实际电机行为**（正转 / 静止 / 倒转）。**只从车端已有历史日志里找证据，缺失标"未知"；
> 不要求队友为取证新增任何运动（不发正/负 PWM、不接电调、不推车）。**

---

## 0. 背景：三个 PWM 值在公式里的含义

| 方向 | v（m/s） | PWM（µs） | 预期物理行为 |
|---|---|---|---|
| 正 | v > 0 | > 1540（如 v=0.55 → 1595） | 前进（正转） |
| 零 | v = 0 | = 1540 | 静止（电调中位） |
| 负 | v < 0 | < 1540（如 v=−0.25 → 1515） | 倒车（反转） |

> 附加事实（REALCAR_CONTROL_AUDIT §8 无动力字节验证）：`T1 零指令→motor=1540`、
> `T2 v=0.25→1565`、`T3 v=−0.25→1515` 是 **pty 虚拟串口的字节级验证**，非真实电机地面行为。
> 用户实测电调死区 ≈ 485 mm/s（v×100+1540 → PWM≈1588）——即"PWM 1588 以下车不动"，
> 所以正转/倒转的真实地面证据必须来自 v 足够大（>0.485）的历史记录。
> ⚠️ 公式偏置 `1540` 是 **0916 标定的历史记录**；另一会话已在车上改 driver、回退、重编译，
> **车端当前偏置待取证**。本表 1540 只作"索取日志时的参照口径"，不作车端当前断言。

## 1. 索取清单（每个方向：从哪找、找什么、缺失怎么标）

### ① 正 PWM（前进）—— 可能已有地面证据

| 找什么 | 来源（车端历史日志） | 判定 |
|---|---|---|
| 发车②（0918 晚）发了 v≈0.55 → PWM≈1595，车真实动了 0.5 m | `~/racecar_team/nav_last.log`（controller 发 `/cmd_vel`）+ `safety_last.log`（透传 0.55）+ `runcar_last.log`（driver stdout `the send buff is: %02x`） | 找到 = 正转**有地面证据** |
| 无动力 T2（v=0.25→1565）、T2b（v=1.0→1640） | 已归档 `docs/validation/2026-09-16-control/dryrun_20260404_162846/` | 字节级，非地面 |

### ② 零 PWM（静止）—— 通常有，但注意「断流保持」陷阱

| 找什么 | 来源 | 判定 |
|---|---|---|
| 静止时 driver 是否真的发过 1540 | `runcar_last.log` 的 `the send buff is` 行（若静止期间有 cmd_vel 零速帧） | 找到 = 静止**有证据** |
| 无动力 T1（v=0→1540） | 已归档 dryrun 日志 | 字节级，非地面 |

> ⚠️ 陷阱：driver **无 watchdog**，断流时**不发任何字节**（下位机保持最后指令），
> 所以「日志里没有 1540 帧」≠「静止没生效」，只是「上游没发零速指令」。如实区分，别把"无日志"当"没静止"。

### ③ 负 PWM（倒车）—— 大概率缺失地面证据

| 找什么 | 来源 | 判定 |
|---|---|---|
| 任何一次真实倒车行驶（v<0 且车向后动）的日志 | `nav_last.log` / `runcar_last.log` / 手柄轮（0917 joy）是否发过负 `/cmd_vel` | 0917/0918 均**未实际倒车行驶**，预计**缺失** |
| 无动力 T3（v=−0.25→1515） | 已归档 dryrun 日志 | 字节级，非地面 |

> 若历史日志无任何倒车地面记录 → **负 PWM 地面行为 = 未知**（如实标注，不推测、不补测）。

## 3. 边界（红线）

1. **不新增运动**：本清单只索取**已有历史日志**，队友**不得**为此接电调、发正/负 PWM、推车、
   或跑任何会动车的新进程。
2. **缺失标未知**：某个方向日志缺失 → 直接写"未知"，**不推断、不脑补、不临时补测**。
3. **字节级 ≠ 地面级**：无动力 dryrun 的字节验证只证明「公式换算正确」，不证明「真实电机按该方向转」；
   两者在回传里**分开标注**，不混为一谈。
4. **不连接车机、不自动 push**：本清单交队友现场执行，我不上车操作。
