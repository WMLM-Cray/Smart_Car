# 多速度训练实验

入口：`python -m fastsim.multispeed`。仅本地实验，不修改车端服务或 PWM 1610 上限。

## 与旧策略的区别

- 原策略 53 维；新实验 54 维，在末尾添加目标速度 / 2.5。
- 所有局的速度观测和前进动作固定按 2.5 m/s 归一化，避免不同速度的数据尺度混淆。
- 目标速度档位为 0.5、0.8、1.2、1.5、2.0、2.5 m/s；一部分采样局在 30 秒内线性变化目标速度。
- 动作执行端限制前进速度不超过目标值，不倒车。历史动作保留网络请求值；这与执行后的动作不同。
- 混合 s1/s3 赛道，DAgger 第一轮教师加转向扰动，后续用学生访问状态、教师给标签。
- 随机化电机时间常数 0.25–0.55 s、舵机速率 2–5 rad/s、加速度 1.5–3 m/s²、横向加速度预算 5–8 m/s²、指令延迟 0–150 ms。

上述动力学区间是训练假设，不是实车标定值。当前模型仍是速度指令驱动，没有模拟实车 ESC 起转台阶或 PWM 1610 对应速度。

## 可复现命令

```powershell
python -m fastsim.multispeed --teacher-only --eval-seeds 3
python -m fastsim.multispeed --legacy-baseline runs/policy_s3.npz --eval-seeds 1
python -m fastsim.multispeed --iterations 2 --episodes 6 --updates 500 --eval-seeds 1 --out runs/multispeed_pilot
```

训练种子从 100000 开始，验证种子从 120000 开始。默认规模不会重叠；扩大到累计 20000 局前需更换区间。
模型从头训练；不加载旧权重。输出每轮 `.pt`、逐局 `.json`，检查点在评估前保存。
按速度分别记录完赛、零碰撞完赛、所有局的碰撞数（含失败局）、横向误差。
正常参数与随机动力学分别评估。默认每局预算 180 s，允许低速跑完整圈。
旧策略对照保留其原来的观测尺度与 120 s 时间输入，只在动作执行端限速。对于原本最高 1.5 m/s 的旧策略，2.0/2.5 档只是放宽上限，并不代表实际跑到该速度。

短流程检查可加 `--budget 8`；这会使正常驾驶也超时，不能据此计算完赛能力。

## 当前边界

教师仍使用已有 SpeedPlanTeacher 的预瞄算法，只限制速度标签；尚未验证针对执行延迟的预瞄补偿。
所以这个实验检查多速度条件训练是否有效，不能宣称已经解决实车转向晚。
单个验证种子仅是流程检查，不能据此选出可靠策略。

下一步需要固定更多验证种子，与旧策略在相同执行速度限制下对照；补充局内变速评估、墙壁/开放弯道和转向增益扰动，以及真正独立的最终测试集。
旧实车推理节点和导出格式不支持新模型，不能直接用新 `.pt` 替换车上的权重。上线前须补齐共享观测、格式版本和推理一致性测试。

## 2026-09-20 本地首轮结果

CPU PyTorch 2.11；固定验证赛道 seed=120000，每档仅一局。以下是诊断结果，不是泛化成功率。

- 教师：六个速度档在标准参数和该次随机动力学下均零碰撞完赛。
- 旧 `policy_s3.npz`：上限 0.5/0.8 m/s 时分别在 47.1%/47.3% 圈处出界；1.2/1.5 m/s 零碰撞完赛。输出见 `runs/multispeed/legacy_baseline.json`。
- 新实验：4 轮，每轮 18 局、1500 次优化，累计 46952 帧。最后一轮标准参数 1/6 完赛，随机动力学 4/6 完赛；两组零碰撞完赛均 0/6。**未达到替换旧策略的条件。** 输出见 `runs/multispeed_pilot_v2/iteration_003.json`，保留所有轮次检查点。
- 50 项训练/推理/遥控相关测试通过。未连接实车，未覆盖旧权重。

下一轮优先拆开变量：先对 0.5–1.5 m/s 做固定动力学训练，再加入变速和延迟。当前实验同时扩大速度和动力学范围，不能从失败直接判断是哪一项造成的。
