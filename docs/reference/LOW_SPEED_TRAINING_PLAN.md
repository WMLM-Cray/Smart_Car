# 低速策略训练计划

状态：2026-09-20 已实现低速专用训练入口并启动 A 阶段（50 万步）。先通过 50 条独立教师赛道检查，再采集训练数据。已有 multispeed 四轮实验不计入本计划预算。B 阶段入口要求 A 阶段验收通过；C 阶段场景和扰动仍待实现，不会自动跳过验收。

## 目标与范围

先实现 0.5–1.0 m/s 的可靠转向，重点是 0.5/0.6/0.8 m/s；1.2 m/s 只用于边界测试。暂不混入 2.0/2.5 m/s。
以上均为物理速度目标，不是 PWM 对应值；不改变车端 PWM 1610 限制。

主实验将学习任务收敛到转向：网络输出前轮转角，速度由给定目标及独立速度控制层决定。仿真先使用现有速度响应模型，实车速度闭环需等编码器及 ESC 低速区间标定后实现。保留原双输出网络作为对照，避免把架构改变带来的差异误算成训练步数效果。
新观测使用雷达、实测速度、目标速度、偏航角速度和上一时刻请求转角，明确固定归一化尺度与格式版本。第一版继续使用 5 帧历史；剩余比赛时间不参与低速转向。观测、叠帧、导出、numpy 推理必须共享定义并测试一致性，不能直接使用旧权重。

## 先验检查：教师必须先合格

在 50 条独立教师开发赛道上逐档测试，含左右弯、S 弯、不同锥桶间距。先用标准动力学；后续每个扰动阶段都重新检查教师。
使用当前预瞄 1.2 m 作基线，对 0.8/1.0/1.2/1.4 m 做离线比较，按零碰撞完赛及车体净空选择，不预设越早转越好。增加预瞄可能切弯。
延迟补偿单独消融，先检验教师是否能处理；教师失败的样本不能直接当正确标签。
从整圈与单弯分别记录首次明显转向位置、车体到锥桶的最小净空、实际转角响应，判断究竟是决策晚还是执行晚。

## 训练预算：按实际新增环境步数计数

一步为一次 20 Hz 控制决策，不能将 batch 重放次数算作新环境交互。

| 阶段 | 新增环境步数 | 内容 | 晋级要求 |
|---|---:|---|---|
| A 几何学习 | 500,000 | 固定 0.6 m/s；标准动力学；教师示范加小幅偏航/横向起点扰动；简单弯和规则赛道 | 开发集零碰撞完赛至少 95% |
| B 低速 DAgger | 1,500,000 | 均衡采样 0.5/0.6/0.8/1.0 m/s；学生闭环采样，教师标注；加入偏离后的恢复状态 | 每档开发集零碰撞完赛至少 95% |
| C 迁移扰动 | 1,000,000 | 先 0–50 ms 再 0–150 ms 延迟；逐项引入转向速率/增益、电机响应；加入局内缓慢变速、墙壁及开放单弯 | 标准条件不明显退化；扰动集每档至少 90% 零碰撞完赛 |

主实验至少 3,000,000 新环境步，是上次 46,952 帧的约 64 倍。每 50,000 新步聚合一次，计划约 60 次聚合。每次先给 2,000–3,000 个 batch 更新、batch=512，总预算约 120,000–180,000 次梯度更新；实际更新数结合独立监督验证误差判断，不为凑数重复过拟合。
阶段未过关不得机械晋级；最多追加到累计 5,000,000 步，仍不达标则停下来检查教师、观测和控制结构，并保留失败结果。
通过后，以另外两个随机初始化各重复至少 3,000,000 步，检查稳定性；三次正式运行的基本预算合计 9,000,000 步，不将其算成一个模型的训练量。

3,000,000 步相当于约 41.7 小时模拟驾驶，不等于电脑运行时间。当前本机 torch 为 CPU 版本；先测 100,000 步的采样、更新和评估耗时，再估算墙钟时长，不预先承诺几小时完成。

## 数据与训练实现要求

- 不同速度和赛道类型独立、均衡抽取；不把一个速度固定配给一种赛道。
- 回放库按速度、正常/恢复状态分层，至少容纳 1,000,000 帧；优先覆盖稀有失败状态，避免低速长局占满样本。
- 第一阶段使用教师示范，随后按预先固定的比例逐步减少教师接管；独立验证始终完全由学生驾驶。
- 每阶段保留标准条件数据，避免只学扰动后忘记正常驾驶。
- 碰撞后不能穿过锥桶继续算成功；记录首次碰撞，评估零碰撞完整任务。完整圈与开放单弯使用不同终点判据。
- 超时预算按路线长度和测试速度预先设定，给启动及恢复留余量，同时记录实际平均速度和停滞；不能通过慢爬/停车获得“安全”高分。
- 每次聚合保存网络、优化器、随机数状态、已用种子、环境步数、回放库及配置，支持真正断点续训。当前 multispeed 只存网络，不满足此要求。

## 验证与最终验收

分离教师开发、训练、模型选择验证、最终测试四组种子及固定赛道文件，确保互不重叠。
现有 seed=120000 已反复查看，只能作为回归案例，不能充当最终测试。

- 每次聚合：10 条固定开发赛道 × 4 档，共 40 局快速检查。
- 每 5 次聚合及晋级前：50 条验证赛道 × 4 档，共 200 局，包含旧策略同条件对照。
- 最终冻结模型后：100 条全新赛道 × 4 档，共 400 局标准测试；另做 400 局扰动测试，以及至少 100 个开放单弯/变速案例。
- 标准条件每档至少 95/100 零碰撞完赛，扰动条件每档至少 90/100；这是经验验收阈值，不能表述为已经统计证明真实成功率达 95%/90%。同时报告二项比例置信区间。
- 报告全部失败、首次碰撞位置、车体净空分位数、转向变化率、实际速度与任务时间；模型选择优先看最差速度档零碰撞表现，再看误差与效率，不按拟合 loss 或最快圈速选模型。

2D 达标后才进入 Gazebo 同路线对照；实车仍需低速标定、推理一致性验证和人工握持使能。2D 过关不是实车安全保证。

## 执行顺序

1. 实现独立低速观测/转向任务、教师评估和真实断点续训，保留现有基线。
2. 跑 100,000 步流水线检查及计时；正确且配置冻结后可计入 A 阶段，否则作废重采。
3. 按 A/B/C 预算训练和晋级，不因少量拟合损失下降提前宣称完成。
4. 冻结候选模型，做多初始化复现及未见赛道验收，输出逐局结果与失败轨迹。

## 当前运行与恢复

```powershell
python -m fastsim.low_speed_train --out runs/low_speed_a
python -m fastsim.low_speed_train --out runs/low_speed_a --resume
```

正式运行日志为 `runs/low_speed_a/train.log`，错误日志为 `error.log`，进程号在 `process.pid`。
`latest.pt` 保存每次聚合结束后的网络、优化器、回放库、随机状态、已用种子索引及环境步数；中断后从最近完整轮次恢复，当前未保存的采样需要重做。
每轮候选 numpy 权重 `candidate_NNN.npz` 使用独立 `low_speed_steering_v1` 格式，不能直接交给旧 ROS 推理节点。
`eval_NNN.json` 是独立学生闭环结果。碰撞立即终止；目标速度固定，不学习油门。

训练 seed 从 10000000 开始，B 从 11000000 开始，教师开发 seed 从 20000000 开始，模型选择验证 seed 从 30000000 开始；最终测试另留独立区间。
左右镜像赛道均覆盖。A 阶段混合简单/规则赛道；初始位置轻微扰动；执行动力学固定。
首轮教师采样，随后逐轮增加学生采样；验证不使用教师接管。
采样按完整 episode 结束，因此阶段和聚合步数可能略超出预算；日志报告实际步数。
本机 CPU 训练。空间不足以原子保存时保留上一份完整检查点并报错，不覆盖成半份文件。

A 阶段通过后，B 阶段命令（尚未启动）：

