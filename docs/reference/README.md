# 历史参考文档

这里保留原先散在 `docs/` 根目录的方案和审查文档。交接文件集中在 [`../handoff/`](../handoff/README.md)。这些资料反映各自写作日期的状态，不作为现行车端配置的统一来源。当前状态先看 [`docs/README.md`](../README.md)；需要复现实验时再打开对应文档，并核对代码版本、原始测量和后续订正。

常见过时口径：0.305/0.36 m 轴距、0.30 m 左右轮中心距、1550 PWM 中位、1610 PWM 前进上限、旧 IP/服务状态，以及“Phase A 尚在初期”的叙述。当前已确定的前后轴距为 **0.33 m**，左右轮中心距为 **0.28 m**。这些旧数字保留在历史报告中，是为了说明当时的判断如何形成。

原始记录在 [`../validation/`](../validation/)，赛道资料在 [`../track/`](../track/)，当前转角训练计划在 [`../research/`](../research/)；本目录没有删除任何旧报告。
