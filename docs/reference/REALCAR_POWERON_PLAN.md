# 实车上电测试方案(2026-09-16,"控制链审查与无动力联调"轮·任务四)

前置:REALCAR_CONTROL_AUDIT.md(控制链审查)已完成,本方案基于其结论。
**本方案只是计划,不代替现场判断;每阶段放行权在车旁的人。**

---

## §0 三阶段总纲(顺序不可换,前一阶段未过不得进入下一阶段)

```
阶段0 停止链路验证(电调断开,舵机通道也验) ──▶ 阶段1 短时低输出(架起悬空)
      ──▶ 阶段2 封闭空地低速行驶(≤0.25m/s)
```

任何阶段异常 → 立即执行 §2 停止优先级,当日不复试,回数据再分析。

## §1 架车固定与转动部件隔离(阶段0/1 通用)

| 项 | 做法 | 说明 |
|---|---|---|
| 架车 | 两块等高垫块(砖/木箱)垫**后轴壳两侧**车身指定抬起点(非底盘塑料件),驱动轮离地 3-5cm,车头朝向空旷方向 | 抬后驱动轮=牵引电机可空转;**前轮(转向轮)保持着地或一并架空**——阶段1 会动舵机,前轮着地会推车,必须四轮离地或前轮垫死 |
| 防翻倒 | 垫块上加止动(楔形块/胶带),或一人扶车尾 | 舵机打满+驱动轮空转有扭矩反作用 |
| 转动部件隔离 | 驱动轮空转半径内不得有人手/线缆;长发/袖口远离;车轮附近 30cm 净空 | 空转轮有飞溅异物风险 |
| LIPO | 放在车外稳固平面,远离转动部件;全程有人值守 | M7 手册安全要求 |
| 场地 | 室内硬质地面,周围 2m 净空,门关好 | 阶段0/1 万一窜车 |

## §2 停止方式与失联处置(优先级从高到低,背下来)

1. **物理断电调开关**(最权威,任何失控第一时间执行;≈1s 内电机失动力);
2. Ctrl+C 收 nav_one.sh / car.sh 链(§审查:driver 退出不发停车字节,但上游停了指令流,
   下位机保持最后指令——**所以软件停止不是可靠停车手段,只是配合**);
3. teleop 停止键(space/k)=发 1540/90 直通中位——**仅当 teleop 在跑且链路活着**才有效;
4. WiFi 失联(SSH 断/遥控无响应)→ 直接执行第 1 条,再排查网络。
   **失联预案**:约定车旁的人在任何测试中手不离开电调开关(或距开关 <1 步)。

**为什么软件停止不可靠(审查实证)**:driver 无 watchdog、退出不发停车、断流不发停车
(CONTROL_AUDIT §2.3/§8 T6/T7)——上游崩溃后车保持最后指令持续行驶,唯一兜底是物理断电。

## §3 牵引电机 vs 舵机供电(审查结论+操作含义)

- 牵引电机动力:LIPO→电调→电机,**电调开关控制**;断开电调=牵引电机无动力。
- **舵机:由 car 控制板供电,car 板由车载电源(拓展坞 USB/车电)供电——与电调开关无关!**
  ⇒ **电调断开≠舵机不能动**:只要 car.sh/nav_one.sh 在跑,任何 /car_cmd_vel、/cmd_vel、
  /teleop_cmd_vel 指令仍会打动舵机(§审查公式:z≠0 → 舵机偏转)。
- 操作含义:①阶段0 验证停止链路时要**把舵机动作也纳入观察**;②架车时若只架空后轮,
  舵机打满仍会推着前轮带车移位——**四轮离地或前轮垫死**;③测试期间前轮回正状态下
  舵机意外大角度=正常公式行为,不是故障。

## §4 上电前三项核对(执行人=用户,逐项打勾)

1. **teleop 版本统一**:车上 install 版 teleop 中位=1540/20,src 版=1550/50(审查 §3.3)。
   处置:统一按 **install 版(1540)** 使用(`ros2 run racecar racecar_teleop.py`);
   src 版 1550 与 driver 公式偏移 1540 不一致,**在重新标定前不启用**。
2. **1540 标定复核**(阶段1 做):v=0 发出的 motor=1540 字节已验证(联调 T1);
   上电后小油门试 1550/1560,观察哪个值电机恰不动——记录实测中位,回填 §审查 §9.6。
3. **确认无人跑语义错位 demo**(car_control_all/my_car_control_new/laser_2d_new/stop_publisher,
   审查 §5.1 ⚠️ 行)——任何时候都不要跑。

## §5 时钟同步方案(多机 ROS 联测前处理;不在运行中的导航会话里跳时)

实测(2026-09-16):车机=2026-04-04 15:57(+0800) vs PC=2026-09-16 21:37(+0800),
**慢 165 天 5h40m**,同时区;车机 NTP inactive(离线无源)。影响:任何跨机比对消息
header.stamp、rosbag 录制时间轴、日志排序都会错 165 天。

处置顺序:
1. **单机跑导航(现状)**:时钟差不影响车自身(nav2 全在车上一台机器,内部时间一致)——
   可先不动;
2. **联测前(要 PC 参与录包/可视化/发目标点时)**:在**启动任何 ROS 会话之前**一次性校时:
   `sudo timedatectl set-ntp false && sudo date -s "@<PC当前unix时间>" && sudo hwclock -w`
   (PC 侧 `date +%s` 取值);校时后开机自检先 `date` 核对;
3. **禁止**:导航/SLAM 会话运行中跳时(会引起 TF 外推错误、AMCL 时间轴断裂);
   校时失败就放弃当次联测,不要带病跑。

## §6 阶段0:停止链路验证(电调断开)

目的:证明"我们能让系统从任何状态回到静止",这是后续一切的安全前提。

| 步骤 | 操作 | 通过判据 |
|---|---|---|
| 0.1 | 确认电调断开;起 **safety_nav_one.sh**(安全链版,§6.5) | 链起、RViz 正常 |
| 0.2 | 观察启动瞬间舵机 | 记录是否抖动(driver 启动不发指令,审查 §2.3;抖动=下位机上电自检,记录幅度) |
| 0.3 | teleop 按 k(发 1540/90 直通中位) | 舵机回正、驱动轮不转 |
| 0.4 | Ctrl+C 收链,人守电调开关 | 收链过程无异常动作(**driver 曾 SIGINT 8s 不退需 SIGKILL,T7;现靠 safety_nav_one.sh 的 trap SIGTERM+兜底 pkill,现场验证**) |
| 0.5 | 重复 0.1-0.4 一次 | 可重复 |

### §6.5 安全链说明(2026-09-16 安全层部署后,启动方式变更)

- 上电阶段一律用 **`~/racecar_team/safety_nav_one.sh`**(不再用厂家 nav_one.sh):
  nav2→**cmd_vel_safety**(NaN/inf 检查、限幅 ±0.10 m/s、0.5s 超时零速、退出零)→/car_cmd_vel→node 版 driver→串口;
  不起厂家 waypoint_cycle(避免自动循环目标)。
- 安全层话题级验证 T11-T16 全 PASS(审计报告 §10);架空阶段观察它上线后 /car_cmd_vel 行为即可。
- **注意**:teleop(/teleop_cmd_vel)不经安全层——它仍是直通通道,阶段0/1 照旧用它测中位与方向。

阶段0 全过 → 才允许合电调。

## §7 阶段1:短时低输出(四轮离地,电调合上)

| 步骤 | 操作 | 通过判据 |
|---|---|---|
| 1.1 | 架车四轮离地(§1),电调合上,起链 | 静止 30s 无自走 |
| 1.2 | teleop 按 i 一下(前进 1560=1540+20?——**按 install 版=1540+20=1560**,弱油门) | 驱动轮缓慢前转,松键回中位即停 |
| 1.3 | teleop 按 , 一下(倒车) | 反向慢转 |
| 1.4 | teleop 按 j/l | 舵机左右偏,回中正常 |
| 1.5 | 油门中位复核:不按键时轮完全静止 | 若缓转→实测中位(§4.2)回填 |
| 1.6 | 断流演练:按住 i 后拔 WiFi(或杀 teleop) | **轮保持转(预期)**→手断电调 → 停。亲证"软件停止不可靠" |
| 1.7 | Ctrl+C 收链 | 无异常 |

## §8 阶段2:封闭空地低速(场地+人员+退出条件)

- 场地:封闭房间/空地,边长 ≥6m,地面平整无障碍,门口拦挡;观众距离 ≥3m;
- 速度:首跑 **v≤0.10 m/s**(新任务书上限;nav_safe.yaml desired_linear_vel=0.10,油门≈1540+10=1550);
  **若该油门低于起步死区(轮不动),先报告,不自行加速**(任务书明令);
- 首跑内容:车头正前方约 1m 单目标(本轮任务书);起点=建图原点位姿,AMCL set_initial_pose+RViz 复核;
  不做循环途经点,首次直行成功后再议转弯;
- 退出条件(任一即停):定位跳变/方向错误/停止失效/通信异常 → 断电调,不连续重试;
- 记录:到达误差、停车行为、定位变化、实际运动(任务书第 5 条)记入 docs/validation/ 对应目录。

## §9 本方案不包含(边界)
- PWM 自动扫描(find_throttle_mid.py 类):本轮明确不做;
- 速度标定(PWM→车速曲线):阶段2 后单独立项(需落地直线 3-5m);
- nav2 参数调整、地图重建:不在上电测试范围。
