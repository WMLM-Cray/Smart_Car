| # | 检查点 | 操作 | 通过标准 | 截图文件名 | 完成 |
|---|---|---|---|---|---|

| A2 | TF 树完整 | TF 显示项开全部 frame | base_footprint→base_link→(steering→front_wheel)×2 + rear_wheel×2 + 传感器 frame,箭头方向合理 | `rviz_a2_tf.png` | ☐ |

## B. 键盘驾驶演示

### B0. 安装键盘遥控(一次性)

```bash
sudo apt install -y ros-humble-teleop-twist-keyboard
```

### B1. 启动遥控(仿真 launch 保持运行)

```bash
export ROS_DOMAIN_ID=42
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

### B2. 演示动线(通过 = 全部完成且无异常)

| # | 动作 | 键位 | 通过标准 | 完成 |
|---|---|---|---|---|
| B1 | 前进 ~2m | `i` | 平稳起步,无异常抖动 | ☐ |
| B2 | 左转 90° 再右转回正 | `j` / `l` | 转向响应及时,半径合理 | ☐ |
| B3 | 倒车 ~1m | `,` | 倒车灯(若有)方向正确,无失控 | ☐ |
| B4 | 停车 | `k` | 立即停稳(watchdog:松手 0.5s 后自动零速也可演示) | ☐ |
| B5 | 急打角极限 | 高速下 `j` 长按 | 舵角饱和 0.55rad 不越界,车仍可控 | ☐ |

## 已知事项

- RViz Fixed Frame 应为 `odom`(odom→base_footprint TF 由 sim_wiring 桥接提供)
- `/clock` 仿真时间下 RViz 偶发时间警告属正常(use_sim_time 一致性已由脚本验收)
- 键盘节点默认速度步长偏大,首次按 `q/z` 调低速档再开
