# 实车运行

部署时保留仓库结构，放在 `/home/orange-pi/autocar`。从该目录执行模块入口；不要继续把文件平铺复制到 web_teleop。

```sh
source vehicle/ros_env.sh
python3 -m vehicle.server
python3 -m vehicle.watchdog
python3 -m vehicle.steer_policy_node models/steering_v1/candidate_060.npz --speed-loop --speed 0.7
```

以上三个进程分别运行。systemd 模板提供网页、看门狗、底盘与旧版策略；系统服务安装仍需在车上验证。标定使用 `python3 -m calibration.loop_test` 等模块入口。

PWM 中位 1540，硬上限 1620，舵机中位 81，轴距 0.33 m。本次没有改变实车服务，也没有进行 ROS 或硬件验收。
