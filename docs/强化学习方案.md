## 2. 任务与关卡

- 只有"沿赛道开":每局一条赛道,从起点(或弯前,见 §2.2)开到终点或开满时长。没有往返、没有房间。
- 关卡全是桶或路沿(和实车一致的那几类),新加一个:

| 关卡 | 说明 | 占比 |
|---|---|---|
| **L5g(新)** | 闭环锥桶赛道,弯外侧桶距 1.6–2.4 m(L5s 是 1.1–1.5);对应实车弯顶 2.16 m 空档 | 0.25 |
| L5 / L5s | 闭环锥桶赛道 | 0.10 / 0.10 |
| L6h / L6f | 锥桶方角大空档 | 0.10 / 0.10 |
| L4 | 混合弯 | 0.05 |
| LW3 / LW4 / LWO3 / LWT3c | 无桶路沿(testset_LW 那一族,防遗忘) | 0.10 / 0.10 / 0.05 / 0.05 |

- `realA_1020` **不进训练**,只当考题。L5g 只加一行 Level(复用 `outer_spacing`),老关卡逐位不变。
- 限速:每局一半和 c027 训练时一样在 0.45–2.5 均匀抽(保住原来的速度泛化),一半在 0.7–1.2(车上常用);评估默认 1.2(10-21 用户定),另有 2.5 的考题盯高速退化(§5)。

### 2.1 一局多长

最长 40 s 或跑完路;到点算截断(末态价值续算),出界 / 截停 / 停滞 / 撞算真结束。

### 2.2 从难弯前开局(本方案最关键的一条)

现在一局大部分拍都在直道上,难弯一局只碰一两次。改成 50% 的局从"难弯前 8 m"开局:
前 4 m 由老师开(把 BEV 历史填满、车速到位,这段不进训练数据),之后交给策略。
难弯 = 中心线 1.5 m 内转角 > 45° 的位置(前后 3 m 内的算同一个弯,每条路 1–5 个)。另外 50% 照常从起点开,保证直道和起步也练到。

## 3. 奖励

每拍(0.05 s):

```
r = Δs                                   沿中心线前进的弧长 m(倒着走为负;单拍裁到 [-0.1, 0.2],防投影跳变)
失败(出界 / 截停 / 撞 / 停滞)时一次性:  r -= C0 + C1 · v²     C0 = 10,C1 = 5(v 为失败时车速)
```

- 不奖励速度本身,也不扣时间:跑得快 = 单位时间 Δs 多,在折扣下自然更好;限速由输入的 cap 管。
- 失败扣分按"损失多少米进度"定:C0 = 10 ≈ 10 m;1.2 m/s 时共 −17.2,2 m/s 时 −30。扣分随车速放大,针对"赌不撞"。
- 出界和截停**同价**(审计:原来 −20 / −5 让模型偏好截停;实车上截停 = 卡死要人管,出界 = 失败,都是失败)。
- 停滞:3 s 内沿路前进 < 0.3 m 算停滞(不看瞬时车速,堵住"慢慢挪"),真结束 + 失败扣分。
- 绕圈刷分不成立:Δs 是沿中心线的弧长,离开路面就出界结束。

## 6. 流程与算力(GCP 虚拟机 8 核)

1. 实现(本地写,虚拟机跑 pytest):L5g、`track_rl`(由 explore_rl 改:赛道任务、近场分支、冻结主干、非对称价值网、

3. 正式 40 轮(估 6–8 h,后台):每 2 轮存候选并在挑模型种子上跑 realA_1020 + L 弯 100 局;
   开局即峰的话,前 10 轮就要仔细看。
4. 挑最好的 1–2 个候选跑完整 §5;全过才提议上车,上车照旧先 Sloth 再 Roaming。
5. 结果写本文档和《项目时间线》。

## 7. 风险

- 仿真动力学:1.2 以上没在实车量过(MAD MAX 的 PWM 曲线待测),抓地力 0.8g 是假设。限速主要放在 0.7–1.2。
- 冻结主干可能限制上限:如果全连接头练不动(Δ 很小),第二步再放开最后一层卷积。
- 弯前开局让难弯样本变多,可能让直道变保守:门槛里的圈速会看出来。
- c027 已能过 realA_1020,RL 的收益主要要在 L5g、testset_LW、L 弯转向时机上看;如果 5 轮试跑看不到任何改善迹象,停下来回到第 1 段做 L5g 关卡的 DAgger 对照。
