## PID(`tune.py`)

被控对象:上面两条曲线 + 10V 估计曲线、θ=0.28s、τ=0.10s、减速上限 0.75 m/s²、编码器噪声 0.02、
整数 PWM。目标序列 0.75→0.9→0.7→0.85,每段后 3 秒算稳态。

| | 12.5V 摆幅 | 11.24V 摆幅 | 停车 |
|---|---|---|---|
| 原来 kp=60 ki=40 | 0.46 m/s / 23 PWM | 0.42 / 18 | 0 |
| kp=8 ki=60 i_limit=80 | 0.08 / 2 | 0.09 / 2 | 0 |
| **kp=8 ki=75 i_limit=80**(采用) | 0.11 / 2 | 0.11 / 3 | 0 |

摆幅 0.08 里大半是编码器噪声本身。kp 5~12、ki 45~60 都差不多,取中间。

改 kp 时仿真暴露一个问题:kp 小时车一起步输出就从破静 PWM 掉到 floor+kp·e,floor 估低时车刚动又停
(floor 信 1560、真刹停 1598:40 秒停 4~10 次),而且没到过目标,自标定触发不了。加了**起步无扰切换**
(积分接住起步时的输出)之后 0 次。

没验证的:τ/θ 怎么分(只有和约束住了);上坡/转弯的负载;实车噪声是不是高斯。

## 起步爬升速率 up_rate(u25~u40.csv)

25/30/35/40 PWM/s 电调都接受,起步 2.8/2.5/2.2/1.9s(20 是 3.2s)。**起步猛不猛和它无关**:
五档动起来后 0.2s 都是 0.45~0.52 m/s —— 电调一过破静点就跳到平台,up_rate 只改死区里空等的时间。
默认仍是 20(40 只跑过一次)。

## 目标低于平台(low05.csv)与前馈尝试

`--plan 0.5:5,0.75:2`:0.5 低于平台,输出压在 floor 1590、车稳在 0.60 m/s(平台已从 0.66 降到 0.60,
电压在掉),**不停、不一冲一停**,floor 没被误抬。切到 0.75 后 2 秒只从 1590 推到 1611、速度 0.64 —— 慢。

试过**在线学的前馈**(记住跑稳时各速度用的 PWM,换目标时把积分放过去),仿真里只有
12.5V 的 0.5→0.75 变快(2.9→1.6s),其他切换超调变大(0.07→0.14)、11.24V 反而变慢。
原因:拐点 1 PWM≈0.05 m/s,学到的值带着量化和噪声,电压一变又过期。**已删掉。**

顺带发现并保留了**向上抗饱和**:PWM 被 up_rate 卡着爬的时候不积分。仿真对比(8 个种子):
12.5V 0.7→0.9 1.7s/+0.11 → 1.2s/+0.07;11.24V 0.5→0.75 3.3s/+0.15 → 2.6s/+0.08;其余持平。
