**用户点名风险**: "gate 是否只是裁大跳变?是否可能让 EKF 沿用旧速度?"
→ v1 **正是**"只裁大跳变"的最小闸门。它不重发旧值,但 **B1 死锁**下真实速度变化被永久拒,
期间 EKF 沿用的正是**最后一条好帧的旧速度**继续预测(最多 2s 到 sensor_timeout)——这正是
"沿用旧速度"风险,后果是 odom 记账滞后于真实位移、AMCL 被拖偏。本机已实证(见 §5)。

**结论**: v1 正确拦截孤立毛刺(⑤⑥场景实证),但 B1/B2/B3 三缺陷使其**不能直接用于持续地面导航**。
修复 = `encoder_fix/encoder_gate_v2.py`(relock 3 帧一致重锁 + 1Hz diag + 帧率观测),
已离线 13/13 单测,**未部署**。按 NEXT_ROUND_PLAN v3,gat 在**阶段 D** 才接入并做四项验证,
且前置 A(字节)/B(解析器)/C(标定)。
