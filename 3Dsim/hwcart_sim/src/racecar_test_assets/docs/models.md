# 模型规格清单（racecar_test_assets）

本文件按任务书要求，对每一类模型逐一说明六项内容：

1. 尺寸 / 单位 / 原点 / 朝向 / 地面高度；
2. visual（视觉）与 collision（碰撞）几何关系；
3. 材质 / 贴图 / mesh 的**包内相对路径**（全部 `model://` 解析，不依赖绝对路径）；
4. 外部素材来源与许可证；
5. 雷达 / 相机检测能力，以及**未测试项**（如实标注）；
6. 红绿灯切换控制接口（或注明为静态）。

**通用约定**：单位一律为米（m）与弧度（rad）；世界坐标系 Z 轴向上，
地面顶面在 z=0；所有模型 `static=true`（测试夹具，验证感知与尺寸，不验证
撞倒/位移判罚）。所有尺寸除注明"规则值"外均为**假设值**，唯一来源是
`tools/asset_params.py`，修改后需按 README「变更流程」重新生成并跑测试。
尺寸的"唯一来源"关系由 `tools/check_models.py`（SDF/STL 对照参数）与
`tools/validate_assets.py`（只读交付文件实测）双重把关。

> 视觉与碰撞的几何一致性约定：除标志牌牌面外，所有模型的 visual 与
> collision 使用**同一几何体**（同尺寸 box/cylinder/sphere，锥桶为同一 STL），
> 仅视觉多一层材质。标志牌牌面 visual 多一层贴图材质脚本，collision 为无贴图
> 的裸 box（见 §4）。

## 7. 关于"随机生成"的说明（无随机种子）

本包所有资产均为**确定性生成**，**不含随机数，无需种子**：

- 锥桶锥台为固定 24 段离散、固定底/顶直径；
- 标志牌贴图为固定白底黑字（字母 A/B 固定）；
- 世界布局为固定 CSV 坐标。

确定性由 `test/test_determinism.sh` 保证：同一输入两次生成字节级一致，
且与仓库内提交文件零漂移。唯一可能跨机器不一致的是标志牌贴图（依赖系统
字体），但**交付以已提交 PNG 为准**，无需重新生成；若确需重生成，请沿用
已提交 PNG 而非依赖本机字体。
