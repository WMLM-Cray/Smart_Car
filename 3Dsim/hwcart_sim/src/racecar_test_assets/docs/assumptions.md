# 建模假设清单（racecar_test_assets 第 3 轮：五类模型 + demo_world）

本包中所有尺寸分为两类：

- **规则值（RULE）**：竞赛规则明确规定、必须满足的尺寸（本包脚本会自动校验）；
- **假设值（ASSUMPTION）**：规则与任务书**未规定**、由本包自行选定、**等待主办方/主开发者确认**的尺寸。

凡未注明"规则值"的数字均为假设值，**不得当作实测值使用**。
所有参数的唯一来源是 `tools/asset_params.py`；修改任何假设值后需按 README
"变更流程"重新生成产物并跑测试。

## 8. 车辆起始位姿（建议，待主开发者确认）

- `base_footprint`：(0, 0, 0)，yaw = 0（朝 +X）；
- 激光雷达（主工程参数）：相对 base_footprint (0.07, 0, 0.21)；
- 由此激光正前方到参考盒前表面（x = 7.75 m）的理论距离为
  **7.68 m = 7.75 − 0.07**。注意：**7.75 m 是世界原点起算的距离，
  7.68 m 才是激光测距的预期值**，两者不可混用。

## 9. 静态模型的固有局限

所有道具均为 `static=true`（永不移动）。这意味着：

- 雷达/相机测试、尺寸核对、坐标核对均有效；
- **无法**验证"撞倒锥桶""推动锥桶位移"类判罚逻辑；
- 如后续需要动态锥桶，需另行建模（含惯性参数），属于后续轮次范围。
