# 雷达项目交付说明

本文件夹是从原目录整理出的可交付版本，原目录中的文件未删除或改动。

## 已整理内容

- `README.md`：雷达数据采集、解析和可视化说明
- `car_ssh.py`、`grab_scan.py`、`parse_bag.py`、`view_scan.py`、`compare_scans.py`：工具脚本
- `scan1/`～`scan4/`：4 组实测数据，均保留原始 `.db3`、`metadata.yaml`、解析后的 `.npz` 和预览图
- `compare_scans.png`：多组扫描数据对比结果图
- `Auto_Car-main/`：小车仿真、训练、遥控及相关文档源码
- `.car_env.example`：连接配置模板

## 未纳入交付

- `.car_env`：包含车辆 SSH 密码，已出于安全原因排除
- `__pycache__/`：Python 运行缓存，无交付价值
- `Auto_Car-main.zip`：与 `Auto_Car-main/` 重复的压缩副本

## 使用配置

需要连接车辆时，将 `.car_env.example` 复制为同目录的 `.car_env`，再填入真实连接信息。真实 `.car_env` 只应保存在本机，不要上传或发送。

## 快速查看

```bash
python view_scan.py scan1/scan.npz --out scan1/overview_check.png
python compare_scans.py --dir scan1 scan2 scan3 scan4
```
