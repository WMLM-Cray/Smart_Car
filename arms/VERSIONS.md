## 一、规矩

1. **生产件零字节改动**：实验只改 `arms/corridor_arm.py`；不碰队友的工作树、不碰索引、
   不改 `common/`、`vehicle/` 里已在用的行为。
   v5.0_Y 起宿主改成仓内 `arms/arm_host.py`（队友 `teleop/road_policy_node.py` 的薄宿主），
   规矩原文里"只猴补队友 teleop"这一句随之作废。
2. **改前先存档**：`cp` 到 `arms/history/corridor_arm__vN_<臂>_<日期>.py` 并记 SHA256；
   `arms/history/` 只读、永不改（该目录现在在归档分支）。
   v3.6_N / v3.7_NP / v3.8_NPR 当年漏了这一步，字节不可复原，只能靠各局 `policy.csv.ver`
   的参数串追溯 —— **今后改代码先 cp 再动**。
3. **改完升版本号**：`ARM_VERSION` 升位并记 SHA256；同一个版本号不许对应两份字节。
4. **每局自带版本指纹**：每局目录里的 `policy.csv.ver` 第一行是版本号 + 全部环境旋钮，
   第二行是 `arm_file=` / `arm_sha256=` / `git_head=` / `started=` / `model_sha256=`。
   ⇒ 要反查某一局用了哪份代码，看这一局自己的 `.ver`，不用查表。
   （2026-10-08 补：这条规矩原来只写在文档里，实现只写版本号 + 旋钮，SHA256 / HEAD / 时间
   一直没落进去；现在由 `_report_version()` 真的写出来。）
5. **仪器脚本**：本仓的跑批脚本
   在 `evaluation/`（`corridor_arm_run.sh`、`ad_arm_solo_batch.sh`、`ad_cap_status.sh`、
   `ad_lap_verdict.py`），正常跟踪，不再需要 `git add -f`。
6. **每个新版先写预登记**：判据、样本量、口径在跑之前定死，**不许看到结果后改**。
   预登记文档属于实验过程件，不入库（归档分支保留）。
7. **诊断文件一律 `open(path, 'w', buffering=1)`**：v2 的 `_pre_dbg` 用默认 8 KB 缓冲，
   进程被 SIGTERM 时文件是 0 字节，把 G 臂误判成"没触发"。
   **"文件 0 字节"永远不等于"没触发"。**
8. **读中文文本注意编码**：PowerShell `Get-Content` 按 GBK 解码会吃掉中文后的换行
   （`HANDOFF.md` 报 1472 行 vs 实际 3256 行）。行数一律以 `wc -l` 为准，读 `HANDOFF.md`
   带 `-Encoding UTF8`。

## 三、各臂语义

`CORRIDOR_ARM` 决定开哪几层；每一层在 `arms/corridor_arm.py` 里对应一节带注释的代码，
下表只记"这个字母开什么"。

| 臂 | 方向层 | 速度层 | 被拦时改走 |
|---|---|---|---|
| A | —（对照：等价于原节点） | — | — |
| B | 弧道扫描（只在**被拦停**那一刻） | — | 弧道扫描 |
| C | — | 净空反解限速 | — |
| D | 弧道扫描 | 净空反解限速 | 弧道扫描 |
| E | **常驻**走廊中心跟随 | 净空反解 + 走廊宽度 | 走廊中心 |
| F | 常驻走廊中心跟随 | 净空反解 + 走廊宽度 | 走廊中心，失败退弧道 |
| G | **策略输出处提前换弧**：`gap(want) < guard_stop+0.20` 就沿策略原意找**最小修正**（≤0.60 动作≈17°），不是常驻层 | 物理反解限速 `v_allow(gap, guard_stop)`（只在上面那几拍生效） | 弧道扫描（**保留 B 的兜底**） |
| H | 同 G | 同 G | 同 G，但用走廊 `c` 的**符号**否决反向换弧 |
| I | —（方向层不动） | —（不动） | **被拦的那一拍**（不等"车已停"）就在可行弧里搜一条 `margin=0.15`，以 `min(0.90, max(v_allow, 0.45))` 继续走；**换向幅度不限**；卡住时同样先这样走，搜不到才盲倒 |
| J | —（同 I） | —（同 I） | 同 I，但 `KEEP_MAX_SWING = 0.60`：**宁可倒车也不把策略原意翻面**（I 的防作弊对照） |
| K | —（同 A） | —（同 A） | —（同 A，不搜弧） |

**K 的位置在第四列之外**：它改的是"被拦到卡住 3 s 之后"的那条路 —— 生产节点盲倒速度
`cap×0.5`，K 把它夹到 `min(cap, 1.5)×0.5`。所以 K 与"被拦时改走"正交：
**K 只让最后手段更慢，不让它更早触发。**

**W / Y 不是"某一层"**，而是 v4.3_W 定下的整套层配置（在 V 的基础上加 `_detour` 提前换道、
把 `_move_ok` 门槛抬到 `guard_stop`）；到底开哪几层由代码里的 `_use_*()` 决定。
v3.x 起新增的字母（L 以后）语义写在 `arms/corridor_arm.py` 对应小节的注释里。

**Y 与 W 的关系**：`CORRIDOR_ARM=Y` 只把宿主换成仓内薄宿主 + 实测几何，层配置取 W
（`ARM_LAYERS = {'Y': 'W'}`）；`CORRIDOR_ARM=W` 走的是旧宿主 + 旧几何。同一份
`corridor_arm.py` 两个字母都跑得起来，所以"Y 相对 W 的差"读的就是"换宿主 + 换几何"。

## 四、怎么反查某一局

- 2026-10-08 起：看这一局自己的 `runs/<dir>/policy.csv.ver`（规矩 4）——第一行版本 + 旋钮，
  第二行臂文件 SHA256 / git HEAD / 开始时间 / 模型 SHA256。
- 两个版本的面板局：逐局表见归档分支的记录。
- v1 那 27 个目录 ↔ 版本的表、各臂语义的完整沿革、判决索引：归档分支。

## 五、历史教训（细节看归档分支）

**假胜**：B 臂第一版把评分函数里的"净空大"当成"这就是路"，开阔区被系统性掰成直行，
车沿 y≈0 开出赛道 40 m。那一局目录 `..._PREFIX_PUBDIR` 是作废档，**任何数字都不得引用**。
教训：判据里凡是有"越大越好"的项，先问一句"它能不能靠不动车刷出来"。
