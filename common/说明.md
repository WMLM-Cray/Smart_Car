# 共享车辆参数、转向映射与策略推理

保存实测车辆参数、舵机非线性映射、观测编码和策略推理。road_policy 是新版双输出策略；low_speed_policy 是现有实车单转向策略，两者模型不可混用。

`policy_portfolio.py` 是**按目标速度选模型**的档位表:单速专化模型只在各自速度上
有效(选错一档干净率 0.9 -> 0.0),所以只做最近档选择、不插值。它不碰实车控制接口,
`steer_policy_node.py` 接的仍然是一个 .npz 路径。

模型是**自描述**的:`low_speed_policy.scale_for_schema()` 从权重文件里的 `schema`
字段反解出训练时的 SPEED_SCALE(`_s3` -> 3.0,无后缀 -> 1.5),部署时不必再设环境
变量,也不必按目录名猜。`SteeringPolicy.scale` 就是那个值,传给 `observe()` 即可。
