# Smart_Car RL 算法模型归档

《基于局部赛道感知的强化学习控制策略》任务的训练产物与评测数据归档。

> 来源仓库：FZU-ZCC-ADS-Lab/Auto_Car，分支 feat/rl-env
> 口径：全部数据基于 FastSim 仿真，未实车验证。

## 目录

| 目录 | 算法 | 最优模型 | 结论一句话 |
|---|---|---|---|
| [PPO算法模型/](PPO算法模型/) | PPO（保守超参） | candidate_009（eval 97.5%） | 全面略逊于 DAgger 基线，不建议替换 |
| [TD3算法模型/](TD3算法模型/) | TD3（双Q+锚定+交错更新） | **candidate_004**（eval 96.7%） | 与基线持平、圈速全面更快，三者综合最优 |
